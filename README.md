# Змійка

Проста браузерна гра «Змійка».

## Опис

Гра побудована на JavaScript з використанням модульної архітектури:
- `js/core/` — ядро гри, менеджер станів, профілів та подій
- `js/states/` — стани гри (`MenuState`, `PlayState`, `GameOverState`)
- `js/systems/` — системи введення та рендеру
- `js/entities/` — сутності гри (`Snake`, `Cherry`)

## Як запустити

1. Відкрий `index.html` у браузері.
2. Або запусти локальний сервер з каталогу проекту, наприклад:
   - `python -m http.server 8000`
   - `npx http-server .`

## Керування

- Старт гри: кнопка `Старт`
- Рух змійки: стрілки `↑`, `↓`, `←`, `→`

## Профілі та рекорди

- Створюй профілі у модальному вікні "Профілі"
- Рекорди зберігаються для кожного профілю
- Відображається топ гравців та рейтинг

## Файлова структура

- `index.html` — головна сторінка
- `style.css` — стилі
- `js/start.js` — точка входу, ініціалізація гри та робота UI
- `js/core/` — ядро гри
- `js/states/` — стани гри
- `js/entities/` — сутності гри
- `js/systems/` — системи гри
- `js/config.js` — конфігурація та налаштування гри

## Примітка

`js/start.js` завантажується як модуль у `index.html` і запускає гру, тому важливо зберегти саме цей файл як entrypoint.
